# Telegram-бот «Белнефтестрах»

Бот со страховой викториной (9 вопросов), информацией о компании и сбором
контактов кандидатов на вакансии. Заявки и результаты викторины отправляются
администратору в Telegram.

## Требования

- Python 3.10+
- Аккаунт бота, созданный через [@BotFather](https://t.me/BotFather)

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

Секреты читаются из переменных окружения — в коде их нет.
Скопируйте пример и заполните своими значениями:

```bash
cp .env.example .env
```

| Переменная  | Описание                                                       |
|-------------|----------------------------------------------------------------|
| `BOT_TOKEN` | Токен бота от @BotFather                                        |
| `ADMIN_ID`  | Числовой Telegram ID администратора (узнать: [@userinfobot](https://t.me/userinfobot)) |

Файл `.env` добавлен в `.gitignore` — не коммитьте его.

## Запуск

```bash
python bot.py
```

Если переменные не заданы или заданы неверно, бот не стартует и выводит
понятное сообщение об ошибке.

## Примечания

- Состояние пользователей хранится в памяти процесса: после перезапуска
  незавершённые анкеты и викторины сбрасываются. Бот корректно сообщает
  пользователю, что сессия устарела, и предлагает начать заново.
- Должен быть запущен только один экземпляр бота — иначе Telegram вернёт
  ошибку `Conflict`, о чём бот уведомит администратора.
